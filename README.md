# mst_test

# Архитектура

Использованы слои из Clean Architecture, для четкого разграничения ответственности

# Структура проекта

В проекте 3 экрана: Onboarding, Subscriptions, Main  
Переходы на каждый последующих сохраняются в SharedPrerefences для того, чтобы повторно не отображаться
